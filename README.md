# 基于边缘AI与LSTM预测的多节点煤堆智能温度监测与主动降温系统

本项目面向煤堆、管廊及工业堆料场景中的温度异常、热积累和火灾风险问题，设计了一套集“多节点感知、无线通信、边缘计算、AI预测、远程监控与主动降温”于一体的软硬件智能监测系统。

系统以 STM32G431 为下位机核心，完成多路温度、压力及电池状态等数据采集，并通过 LoRa 无线通信发送至 STM32MP157 边缘计算网关。网关端运行 Qt 可视化监控程序，并结合 LSTM 模型对温度变化趋势进行预测，实现对潜在高温风险的提前判断。

当系统检测到温度异常或预测结果达到风险阈值后，可自动生成降温控制指令，并通过 LoRa 下发至执行节点，驱动水泵等设备进行主动降温，从而形成：

**环境感知 → 数据传输 → AI预测 → 风险判断 → 自动控制 → 状态反馈**

的完整闭环控制流程。

同时，系统支持 MQTT/EMQX 数据通信与 Web 端远程监控，可实时查看各监测节点的温度、压力、电量、设备状态、历史曲线及报警信息。

## 主要功能

- 多节点、多通道温度实时采集
- 压力与设备电量状态监测
- LoRa 远距离无线通信
- STM32MP157 边缘计算网关
- Qt 本地可视化监控平台
- LSTM 温度趋势预测
- AI辅助风险预警
- 超温自动降温控制
- MQTT/EMQX 云端数据通信
- Web 远程监控与历史数据展示
- 传感—预测—决策—执行闭环控制

## 关于程序运行

本项目属于软硬件一体化实体系统，完整运行依赖 STM32MP157、STM32G431、LoRa 通信模块、温度及压力传感器、水泵执行机构等硬件设备，因此无法在普通计算机上脱离硬件环境完整复现。

本仓库用于提供项目核心软件代码、Web 监控程序、边缘端程序及相关运行说明。完整的软硬件联调过程、AI预测过程以及自动降温闭环效果，请参见 iCAN AI 创新挑战赛作品演示视频。
